# Track A: Gradebook Management System

A comprehensive gradebook application demonstrating OOP, SQLite databases, and CRUD operations.

## Features
- Student management with grade levels
- Assignment grade tracking
- Statistical analysis (averages, scores)
- Report card generation and export
- Relational database with foreign keys

## Requirements Met
- ✅ 5+ Functions
- ✅ 3+ Try-Except Blocks
- ✅ Custom Exception Handling
- ✅ OOP Inheritance (Person → Student)
- ✅ Method Overriding (__str__)
- ✅ SQLite Relational Tables
- ✅ 8+ Git Commits
