# Track D: Expense Tracker / Budget Manager

A comprehensive budget management application demonstrating OOP, SQLite databases, and threshold alerts.

## Features
- Category-based expense tracking
- Monthly budget limits per category
- Automated budget threshold warnings
- CSV export functionality
- Transaction history management
- Relational database with JOIN queries

## Requirements Met
- ✅ 5+ Functions
- ✅ 3+ Try-Except Blocks
- ✅ Custom Exception Handling
- ✅ OOP Inheritance (FinancialEntry → ExpenseTransaction)
- ✅ Method Overriding (__str__)
- ✅ SQLite Relational Tables
- ✅ 8+ Git Commits
